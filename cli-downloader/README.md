# CLI downloader

Legacy interactive Python tools for Spotify/Beatport metadata conversion and YouTube audio matching.

## Run

Windows:

```bat
run_spotify_downloader.bat
```

macOS or Linux:

```sh
./run_spotify_downloader.sh
```

The launcher creates an `env/` virtual environment inside this directory and presents the available CLI workflows.

For a graphical interface, configurable formats, history, playback, and packaged desktop releases, use [`../desktop-downloader/`](../desktop-downloader/).
